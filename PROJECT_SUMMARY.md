# Обзор Проекта "Магазин Подшипников"

Этот документ описывает текущее состояние проекта, реализованные функции и его структуру. Он был создан для документирования проделанной работы.

## 1. Общее описание

Проект представляет собой веб-сайт на базе **Django** для продажи промышленных подшипников. Он включает в себя каталог товаров, систему поиска и интеграцию с Telegram для взаимодействия с пользователями.

## 2. Реализованные Функции

За время работы были добавлены и улучшены следующие ключевые функции:

### а) Современный Интерфейс и Навигация
- **Базовый шаблон:** Создан основной шаблон (`templates/base.html`), который обеспечивает единый внешний вид для всего сайта.
- **Интеграция Bootstrap 5:** Весь интерфейс стилизован с помощью современного CSS-фреймворка Bootstrap 5, что делает сайт адаптивным и приятным для просмотра на любых устройствах.
- **Редизайн главной страницы:** Главная страница была переработана, чтобы стать более информативной и профессиональной.

### б) "Живой" Поиск по Каталогу
- **Интерактивные подсказки:** В навигационную панель встроена поисковая строка, которая в реальном времени показывает выпадающий список с подходящими товарами по мере ввода запроса.
- **Подсветка совпадений:** Часть текста в названии товара, совпадающая с запросом, выделяется цветом для удобства пользователя.
- **API для поиска:** Для реализации этой функции был создан специальный API-эндпоинт (`/api/search-suggestions/`).

### в) Страницы Детализации Товаров
- **Информационные страницы:** Для каждого товара создана отдельная страница (`/product/<id>/`), на которой отображается вся доступная информация:
  - Маркировка и производитель
  - Подробное описание
  - Технические характеристики (вес, габариты)
  - Цены (розница, опт)
  - Наличие на складах
- **Интеграция с поиском:** "Живой" поиск теперь напрямую ссылается на эти страницы.

### г) Telegram-бот
- **Поиск в Telegram:** Создан Telegram-бот, позволяющий пользователям искать товары из каталога прямо в мессенджере с помощью команды `/search`.
- **Безопасность:** Бот настроен на безопасное чтение API-ключа из `.env` файла, который не хранится в системе контроля версий.
- **Автономная работа:** Бот является самостоятельным скриптом, который работает параллельно с основным Django-сайтом.

## 3. Структура Проекта

- **`config/`**: Основная папка конфигурации Django (настройки, URL-адреса).
- **`catalog/`**: Django-приложение, содержащее всю логику каталога товаров (модели, views, шаблоны).
- **`templates/`**: Папка в корне проекта, содержащая базовый шаблон сайта.
- **`tgbot/`**: Папка с исходным кодом, инструкциями и зависимостями для Telegram-бота.
- **`requirements.txt`**: Файл с перечнем Python-библиотек, необходимых для работы сайта и бота.
- **`.env` (не отслеживается Git)**: Файл для хранения секретных ключей, таких как токен Telegram-бота.

## 4. Инструкции по запуску

### Запуск веб-сайта
```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера разработки
python manage.py runserver
```
Сайт будет доступен по адресу `http://127.0.0.1:8000/`.

### Запуск Telegram-бота
```bash
# Убедитесь, что создан .env файл с токеном
# (инструкции в tgbot/README.md)

# Запуск бота из корневой папки проекта
python tgbot/bot.py
```
