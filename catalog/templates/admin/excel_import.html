Что принимает файл

Ровно 16 колонок в таком порядке: Родительская категория, Категория, Код, Маркировка, Производитель, Описание, Вес, Длина, Ширина, Высота, Склад, Количество, Зарезервировано, Свободно, Цена Розница, Цена Опт.

  • Код — стабильный идентификатор товара. Он обновляет существующую карточку; новая строка с новым кодом создаёт товар.
  • Если код пустой, файл можно загрузить только в пустой каталог или повторить без изменений. Для последующих правок сначала выгрузите каталог с кодами.
  • Пустая цена или ошибка Excel в цене означает «цена не указана»: существующая цена остаётся прежней, для нового товара цена будет по запросу.
  • «Свободно» вычисляется из количества и резерва. Товары и склады, которых нет в файле, не удаляются.
