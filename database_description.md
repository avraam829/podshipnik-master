# 📘 Описание базы данных

## Общая идея

База данных предназначена для хранения:
* каталога товаров,
* иерархии категорий,
* складских остатков,
* цен (розница / опт),
* информации о пользователях,
* данных о корзинах покупок.

---

# 1️⃣ Таблица `users` — пользователи

### Назначение

Хранит информацию о пользователях сайта, включая данные для аутентификации.

### Структура

| поле      | тип                  | описание                                      |
| --------- | -------------------- | --------------------------------------------- |
| id        | INT (PK)             | уникальный идентификатор пользователя         |
| username  | VARCHAR(150), UNIQUE | имя пользователя                              |
| password  | VARCHAR(128)         | хешированный пароль                           |
| email     | VARCHAR(254)         | адрес электронной почты                       |
| first_name| VARCHAR(150)         | имя                                           |
| last_name | VARCHAR(150)         | фамилия                                       |
| is_active | BOOLEAN              | активен ли пользователь                       |
| is_staff  | BOOLEAN              | имеет ли пользователь доступ к админ-панели   |
| is_superuser | BOOLEAN           | является ли пользователь суперпользователем   |
| last_login | DATETIME            | дата последнего входа                         |
| date_joined| DATETIME            | дата регистрации                              |

### Логика

* Расширяет стандартную модель `AbstractUser` Django.
* Позволяет гибко настраивать поля пользователя в будущем.

---

# 2️⃣ Таблица `categories` — категории и подкатегории

### Назначение

Хранит иерархию категорий товаров.
Одна таблица поддерживает **любую глубину вложенности**.

### Структура

| поле      | тип                      | описание                          |
| --------- | ------------------------ | --------------------------------- |
| id        | INT (PK)                 | уникальный идентификатор          |
| name      | VARCHAR(255)             | название категории                |
| parent_id | INT (FK → categories.id) | родительская категория или `NULL` |

### Логика

* `parent_id = NULL` → корневая категория
* несколько категорий могут иметь `NULL`
* подкатегории ссылаются на родителя
* удаление родителя удаляет дочерние категории

---

# 3️⃣ Таблица `products` — товары

### Назначение

Хранит карточки товаров (подшипники, ремни, втулки и т.п.).

### Структура

| поле         | тип                      | описание                 |
| ------------ | ------------------------ | ------------------------ |
| id           | INT (PK)                 | ID записи                |
| code         | VARCHAR(100), UNIQUE     | внутренний код компании  |
| designation  | VARCHAR(255)             | маркировка производителя |
| manufacturer | VARCHAR(100)             | производитель            |
| description  | TEXT                     | техническое описание     |
| weight       | DECIMAL(10,3)            | вес                      |
| length       | DECIMAL(10,2)            | длина                    |
| width        | DECIMAL(10,2)            | ширина                   |
| height       | DECIMAL(10,2)            | высота                   |
| category_id  | INT (FK → categories.id) | категория товара         |
| price        | DECIMAL(10,2)            | цена товара              |

### Логика

* `code` — **внутренний идентификатор**, не для поиска
* поиск выполняется по `designation`, `manufacturer`, `description`
* товар принадлежит **одной категории**
* категорию можно менять без изменения товара

---

# 4️⃣ Таблица `warehouses` — склады / места хранения

### Назначение

Хранит список складов и мест хранения.

### Структура

| поле | тип                 | описание            |
| ---- | ------------------- | ------------------- |
| id   | INT (PK)            | ID склада           |
| code | VARCHAR(50), UNIQUE | код склада          |
| name | VARCHAR(255)        | название / описание |

### Логика

* склад — это физическое место хранения
* один склад содержит много товаров

---

# 5️⃣ Таблица `stocks` — остатки на складе

### Назначение

Связывает товары и склады, хранит количество и резерв.

### Структура

| поле         | тип                      | описание         |
| ------------ | ------------------------ | ---------------- |
| id           | INT (PK)                 | ID записи        |
| product_id   | INT (FK → products.id)   | товар            |
| warehouse_id | INT (FK → warehouses.id) | склад            |
| amount       | INT                      | общее количество |
| reserved     | INT                      | зарезервировано  |
| free         | INT                      | свободно         |

### Логика

* уникальность: `(product_id, warehouse_id)`
* `free = amount - reserved`
* товар может быть на нескольких складах
* склад может содержать много товаров

---

# 6️⃣ Таблица `prices` — цены

### Назначение

Хранит цены товаров разных типов.

### Структура

| поле       | тип                    | описание                         |
| ---------- | ---------------------- | -------------------------------- |
| id         | INT (PK)               | ID записи                        |
| product_id | INT (FK → products.id) | товар                            |
| price_type | VARCHAR(20)            | тип цены (`retail`, `wholesale`) |
| price      | DECIMAL(10,2)          | цена                             |

### Логика

* уникальность: `(product_id, price_type)`
* один товар может иметь несколько типов цен
* добавление новых типов не требует изменения структуры БД

---

# 7️⃣ Таблица `carts` — корзины пользователей

### Назначение

Хранит информацию о корзинах пользователей.

### Структура

| поле       | тип                    | описание                             |
| ---------- | ---------------------- | ------------------------------------ |
| id         | INT (PK)               | ID корзины                           |
| user_id    | INT (FK → users.id)    | пользователь, которому принадлежит корзина |
| created_at | DATETIME               | дата создания корзины                |

### Логика

* Один пользователь может иметь только одну активную корзину.
* Связь `OneToOneField` с моделью `User`.

---

# 8️⃣ Таблица `cart_items` — товары в корзине

### Назначение

Хранит товары, добавленные в каждую корзину.

### Структура

| поле       | тип                    | описание                       |
| ---------- | ---------------------- | ------------------------------ |
| id         | INT (PK)               | ID записи                      |
| cart_id    | INT (FK → carts.id)    | корзина, к которой относится товар |
| product_id | INT (FK → products.id) | товар в корзине                |
| quantity   | INT                    | количество товара              |

### Логика

* Связь `ForeignKey` с моделями `Cart` и `Product`.
* Позволяет хранить несколько единиц одного и того же товара.

---

# 🔗 Связи между таблицами

```
users
  ↑
carts
  ↓
cart_items → products

categories
   ↑
products
   ↓
stocks → warehouses

products → prices
```

# 🔍 Поиск

* поиск осуществляется **семантически**:
  * `designation`
  * `manufacturer`
  * `description`
* аналоги определяются **динамически** по совпадениям, без жёстких связей
