# Telegram-бот для магазина подшипников

Этот бот предназначен для взаимодействия с каталогом товаров вашего Django-сайта прямо из Telegram.

## Возможности

- **/start**: Приветственное сообщение.
- **/help**: Помощь по доступным командам.
- **/search &lt;запрос&gt;**: Поиск товаров в каталоге по названию, маркировке или производителю.

## Установка и запуск

1.  **Установите зависимости:**
    Убедитесь, что у вас активировано виртуальное окружение. Затем выполните команду:
    ```bash
    pip install -r requirements.txt
    ```

2.  **Создайте файл `.env`:**
    В корневой папке проекта (`bearings_shop`) создайте файл с именем `.env` и добавьте в него ваш API-ключ, полученный от @BotFather. **Никогда не сохраняйте этот файл в Git!**

    ```
    TG_BOT_TOKEN="ВАШ_НОВЫЙ_API_КЛЮЧ"
    ```

3.  **Запустите бота:**
    Для запуска бота выполните команду из корневой папки проекта:
    ```bash
    python tgbot/bot.py
    ```

Бот начнет работать и будет отвечать на команды в Telegram.
