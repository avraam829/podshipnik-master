# Cистема управления каталогом подшипников

Этот проект представляет собой веб-приложение на Django, предназначенное для управления каталогом промышленных товаров (подшипники, ремни и т.д.), складскими остатками и ценами.

## 🚀 Как запустить проект

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <адрес_репозитория>
    cd bearings_shop
    ```

2.  **Установите зависимости:**
    Убедитесь, что у вас установлен Python. Затем создайте и активируйте виртуальное окружение.

    ```bash
    # Создать виртуальное окружение (для Windows)
    python -m venv .venv
    # Активировать его
    .venv\Scripts\activate
    ```
    Установите зависимости:
    ```bash
    pip install -r requirements.txt 
    ```
    *(Примечание: `requirements.txt` нужно будет создать, если его нет: `pip freeze > requirements.txt`)*


3.  **Примените миграции базы данных:**
    Это создаст таблицы в базе данных `db.sqlite3` на основе моделей.
    ```bash
    python manage.py migrate
    ```

4.  **Импортируйте данные (опционально):**
    Проект содержит команду для импорта данных из `prepared_for_db.json`.
    ```bash
    python manage.py import_catalog --file prepared_for_db.json
    ```

5.  **Создайте суперпользователя:**
    Это необходимо для доступа к административной панели.
    ```bash
    python manage.py createsuperuser
    ```

6.  **Запустите сервер для разработки:**
    ```bash
    python manage.py runserver
    ```
    Приложение будет доступно по адресу [http://127.0.0.1:8000/](http://127.0.0.1:8000/).
    Админ-панель: [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/).

## Основной функционал

### 1. Приложение `catalog`

Это ядро системы. Оно отвечает за всё, что связано с товарами.

-   **`models.py`**: Определяет структуру базы данных.
    -   `Category`: Иерархические категории товаров.
    -   `Product`: Карточка товара (маркировка, производитель, размеры).
    -   `Warehouse`: Места хранения (склады).
    -   `Stock`: Остатки товаров на складах.
    -   `Price`: Цены на товары (розница, опт).
    *Подробное описание полей есть в файле `database_description.md`.*

-   **`views.py`**: Обрабатывает HTTP-запросы и возвращает пользователю страницы.
    -   `index`: Главная страница со списком корневых категорий.
    -   `category_view`: Страница категории, отображает подкатегории и товары.
    -   `search`: Логика поиска по каталогу. Поиск ведется по маркировке, производителю и описанию.

-   **`urls.py`**: Связывает URL-адреса с функциями из `views.py`.
    -   `/`: Главная страница.
    -   `/category/<id>/`: Страница категории.
    -   `/search/`: Страница результатов поиска.

-   **`management/commands/import_catalog.py`**:
    Очень важный скрипт, который парсит `prepared_for_db.json` и наполняет базу данных: создает категории, товары, склады, остатки и цены.

### 2. Конфигурация `config`

-   **`settings.py`**: Главный конфигурационный файл Django. Здесь подключаются приложения (`catalog`), настраивается база данных и другие параметры.
-   **`urls.py`**: Основной файл URL-маршрутизации. Он включает в себя все URL из приложения `catalog` и добавляет путь для админ-панели (`/admin/`).

### 3. База данных

-   Используется `db.sqlite3` — легковесная файловая база данных, отлично подходящая для разработки.
-   Структура таблиц подробно описана в файле `database_description.md`.
