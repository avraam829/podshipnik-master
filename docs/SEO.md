# SEO
Товары имеют серверные страницы /podshipniki/<saved-slug>/; slug содержит исходное обозначение в URL-форме и устойчивый код. Старый /product/<id>/ возвращает HTTP 301 сразу на сохранённый адрес. Несуществующий товар и недопустимая страница каталога возвращают 404.

Title/H1/description используют реальные designation/brand/price. Оригинальное обозначение в контенте не нормализуется. Один canonical; OpenGraph URL использует SITE_URL. Product JSON-LD сериализуется с экранированием <; отзывы/ratings/availability не выдуманы. Offer сознательно не добавлен: заказ требует подтверждения менеджера и наличие условное.

sitemap.xml — индекс, товары разбиты по 5000 URL; sitemap-pages.xml содержит главную, каталог, контакты; sitemap-categories.xml содержит категории. Поиск, filters, users/cart/API имеют noindex. Crawlable пагинация ?page=N. Manufacturer filter выводит только реальные значения manufacturer; выдуманные бренды/SEO-страницы не создаются.

Для проверки:
```sh
python manage.py test catalog
python scripts/browser_check.py
```
JSON-LD проверяется JSON-парсером и соответствием видимому обозначению; внешние Google Rich Results/Schema Validator требуют отдельной проверки опубликованного HTTPS URL. Автоматические тесты не равны подтверждению индексации Google/Яндекс.

После публикации: проверить canonical/301/404, отправить sitemap в Search Console и Яндекс Вебмастер, проверить индексируемость на реальных product URL. Первые места и упоминания LLM не гарантируются. llms.txt не заменяет серверный HTML и полезные страницы.


Для диагностики индексации владелец должен проверить:

1. Яндекс Вебмастер: «Индексирование → Страницы в поиске → Исключённые
   страницы» и анализ конкретного URL. В Google Search Console — проверку
   URL и отчёт об индексировании страниц. Сохранить точную причину исключения.
2. Добавить `https://gpz5.ru/sitemap.xml` в оба кабинета и убедиться, что
   поисковик успешно читает его. Сам sitemap не гарантирует индексацию.
3. Выбрать приоритетные карточки и заполнить достоверные характеристики:
   размеры, исполнение, материал, применяемость, реальные чертежи/фото и
   условия поставки, когда эти данные доступны. Не генерировать выдуманные
   размеры или аналоги ради текста.
4. Отправить исправленные карточки на переобход. Отличать отсутствие страницы
   в индексе от низких позиций уже проиндексированной страницы.
