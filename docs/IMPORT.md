# Импорт каталога из Excel

Импорт выполняется в админке: **Товары → Импорт / проверка Excel**. Сначала скачайте пустой шаблон либо выгрузите товары действием «Выгрузить выбранные товары в Excel». Для регулярного обновления выбирайте выгрузку каталога: в ней уже есть стабильные коды товаров.

Без записи в базу можно проверить файл из командной строки:

```sh
docker compose cp catalog.xlsx web:/tmp/catalog.xlsx
docker compose exec web python manage.py import_xlsx /tmp/catalog.xlsx
```

После проверки запись выполняется только с явным параметром:

```sh
docker compose exec web python manage.py import_xlsx /tmp/catalog.xlsx --apply
```

## Формат файла

Принимается `.xlsx` с одним активным листом, максимум 100 000 строк данных и ровно 16 колонками в следующем порядке:

| № | Колонка | Правило |
|---:|---|---|
| 1 | Родительская категория | Необязательна |
| 2 | Категория | Необязательна |
| 3 | Код | Стабильный идентификатор товара |
| 4 | Маркировка | Обязательна |
| 5 | Производитель | Необязателен |
| 6 | Описание | Необязательно |
| 7 | Вес | Неотрицательное число, до 3 знаков после запятой |
| 8–10 | Длина, Ширина, Высота | Неотрицательные числа, до 2 знаков после запятой |
| 11 | Склад | Пустое значение означает «Основной склад» |
| 12 | Количество | Неотрицательное целое |
| 13 | Зарезервировано | Неотрицательное целое, не больше количества |
| 14 | Свободно | Расчётное поле экспорта: при импорте вычисляется из количества и резерва |
| 15 | Цена Розница | Неотрицательное число, до 2 знаков после запятой |
| 16 | Цена Опт | Неотрицательное число, до 2 знаков после запятой |

Заголовки и их порядок проверяются. В админке дополнительно действует лимит размера файла 20 МБ. Значения цен с ошибкой Excel (`#VALUE!`, `#N/A`, `#REF!`, `#DIV/0!`, `#NUM!`) не останавливают импорт: появится предупреждение, а такая цена считается неуказанной.

## Как обновляются данные

Код связывает строку с товаром. Новый код создаёт товар, существующий код обновляет характеристики, категорию и остаток на указанном складе. Одна и та же карточка может занимать несколько строк для разных складов; две строки с одним кодом на одном складе запрещены.

Склад сопоставляется по точному названию, поэтому ранее созданный склад с другим (например, старым) кодом будет использован повторно. Если в базе несколько складов с одинаковым названием или технический код нового склада занят другим названием, импорт останавливается ещё на проверке; вручную устраните дубликат в админке.

Пустая цена и цена с ошибкой Excel не обнуляют существующую цену и не удаляют запись цены. Для нового товара такая цена остаётся «по запросу». Чтобы явно перевести розничную цену в «по запросу», укажите `0` в колонке «Цена Розница». Строки товаров, склады и цены, которых нет в новом файле, не удаляются. Импорт никогда не выполняет синхронизацию «файл является полным каталогом».

Если в исходном файле нет кодов, его разрешено загрузить только в пустой каталог. Система присвоит технические коды, зависящие от содержимого файла. Тот же самый файл можно безопасно запустить повторно: он будет показан как «без изменений». Изменённый файл без кодов в непустой каталог загружать нельзя, потому что нельзя надёжно определить, какую карточку нужно обновить. Выгрузите каталог, перенесите правки в эту выгрузку и повторите проверку.

Старый вызов `manage.py import_catalog` для JSON отключён. У него не было устойчивого сопоставления товаров и повторный запуск мог создавать дубликаты. Команда завершается с подсказкой перейти на Excel и ничего не меняет.

## Совместимость с исходной выгрузкой

Поддерживается исходная 16-колоночная выгрузка. Пустые «Код» и «Производитель» допустимы при первом импорте в пустой каталог, количество `9999` допустимо. Ошибки цены, например `#VALUE!` в строках 10926, 11026 и 11420 исходного файла, будут отражены как предупреждения и не подменят действующие цены.
